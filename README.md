# Learn2Earn 5-Day Trials 2026

## Overview

This repository documents my participation and practical learning experience during the **Learn2Earn 5-Day Trials**, organized by Talent Nation.

The five-day programme provided an opportunity to strengthen my foundational programming skills, understand version control workflows, practice structured problem-solving, and gain hands-on experience working with Python and development tools.

It contains learning materials, practical assignments, code implementations, testing evidence, and personal reflections from the trials.

## Objectives

The major objectives of this learning experience were to:

- Understand Git and version control fundamentals.
- Learn how to create, manage, and maintain repositories.
- Develop practical Python programming skills.
- Understand functions, conditional statements, variables, and modular programming.
- Apply structured problem-solving techniques.
- Practice breaking larger problems into smaller components.
- Understand testing, debugging, and code improvement.

## Learning Areas

### 1. Git and Version Control

Explored the fundamentals of version control and collaborative development, including:

- Git and repository management.
- GitHub and Gitea.
- Initializing and cloning repositories.
- Staging and committing changes.
- Pushing and pulling updates.
- Branching and version management.
- Understanding Git workflows.

### 2. Python Programming

Practiced essential Python programming concepts, including:

- Variables and data types.
- Functions and parameters.
- Return statements.
- Conditional statements (`if`, `elif`, and `else`).
- Arithmetic operations.
- Problem decomposition.
- Modular programming.
- Debugging and testing.

### 3. Problem-Solving and Algorithm Design

Developed a structured approach to solving programming problems:

1. Understand the problem.
2. Identify the requirements.
3. Break the problem into smaller tasks.
4. Design the solution and algorithm.
5. Implement the solution using Python.
6. Test and validate the results.
7. Improve the implementation where necessary.

## Getting Started

### Prerequisites

- Python 3 installed.
- Git installed.
- A code editor such as Visual Studio Code.

### Clone the Repository

```bash
git clone https://github.com/Engr-Yina/learn2earn-trials-2026.git
```

Navigate into the project directory:

```bash
cd learn2earn-trials-2026
```

### Running the Python Projects

Run the team mission:

```bash
python event-budget-helper-team-mission/event-budget-helper.py
```

Run the individual mission:

```bash
python personal-budget-helper-solo-mission/improved-solution.py
```

Run the Git demonstration:

```bash
python git-fundamentals/version-control-demo.py
```

*Note: Run these commands from the repository root. Individual files can also be executed separately where appropriate.*
