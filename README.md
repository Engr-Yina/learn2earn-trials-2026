## Projects

### Day 2 — Personal Budget Helper

**Description:** A simple Python program that calculates the money remaining after food and transport expenses and generates a personalised budget message.

**Features**
- Calculates the remaining budget.
- Handles zero expenses.
- Supports negative balances when expenses exceed the budget.
- Generates messages using supplied names and remaining amounts.
- Uses functions that return values.

**Technologies**
- Python 3
- Git
- GitHub
- Gitea

**Example**

```python
remaining = budget_remaining(2000, 900, 600)
print(remaining)
```

Output:

```text
500
```

Message example:

```text
Ada has 500 naira remaining.
```

**Testing**

The project includes tests for:
- Normal budget calculations.
- Zero expenses.
- Overspending.
- Exact message formatting.
- Integration of both functions.
