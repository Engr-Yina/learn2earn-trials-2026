# Event Budget Helper

A simple Python project developed during the Learn2Earn Trials (Days 3 & 4). It calculates event expenses, checks budget limits, and generates event summaries.

## Features
- Calculates participant food and transportation costs.
- Calculates total event expenses, including venue costs.
- Checks whether an event is within or over budget.
- Generates event budget summaries.
- Includes automated tests and input validation.

## Technologies
- Python 3

## How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project folder:
   ```bash
   cd event-budget-helper
   ```

3. Run the program:
   ```bash
   python event-budget-helper.py
   ```

4. Follow the prompts to enter event details.

## Testing

The program automatically runs component tests before starting the interactive application.

## Project Purpose

Built to practise Python functions, modular programming, conditional statements, component integration, testing, and error handling.
