# Learn2Earn Day 1 – Git Fundamentals

## Project Overview

This repository documents my Day 1 learning activities during the Learn2Earn Trials.

The lesson focuses on Git, repositories, commits, Gitea and the basic version-control workflow used by software developers to manage and track changes in their projects.

## Learning Objectives

By completing this project, I aimed to:

- Understand the purpose of version control.
- Explain Git, repositories and commits.
- Differentiate between Git and Gitea.
- Understand the Git save cycle.
- Practise staging, committing and pushing changes.
- Understand the importance of meaningful commit messages.

## Basic Git Workflow

The fundamental workflow covered in this project is:

**Edit → Check → Stage → Commit → Push**

## Practical Demonstration

A simple Python program is included to demonstrate code changes and provide an example project for practising Git version control.

## Key Learning Outcome

I developed an understanding of how Git tracks changes, how commits preserve project history, and how remote hosting platforms such as Gitea and GitHub support collaboration.
