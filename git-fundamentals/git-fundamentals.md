# Git Fundamentals

## 1. What is Git?

Git is a distributed version-control system used to track changes in files and source code.

It allows developers to maintain project history, identify modifications and return to earlier versions when necessary.

## 2. What is Version Control?

Version control is a system that records changes made to files over time.

It helps developers:

- Track project modifications.
- Maintain a history of changes.
- Recover previous working versions.
- Collaborate with other developers.
- Manage different stages of development.

## 3. What is a Repository?

A repository, commonly called a repo, is a project managed by Git, including its tracked files and history.

Example:

A Python project named `student_management` can be managed as a Git repository.

## 4. What is a Commit?

A commit is a recorded snapshot of staged changes in a Git repository.

Each commit has a message describing the changes made.

Example:

`git commit -m "Add student registration function"`

## 5. Why Developers Use Git

- To track changes in source code.
- To maintain project history.
- To collaborate with other developers.
- To manage development safely.
- To identify and resolve problems introduced by changes.

## 6. Conclusion

Git helps developers manage their projects by tracking changes and preserving meaningful snapshots of their work.
